# AI Traffic Analysis System 🚦

An AI-powered Computer Vision project built using Python, OpenCV, and YOLOv11 for real-time traffic analysis and vehicle counting.

## Features

- Real-time vehicle detection
- Vehicle tracking with unique IDs
- Separate counting for:
  - Cars
  - Bikes
  - Buses
  - Trucks
- Live traffic monitoring
- Virtual counting line system
- Optimized for performance

## Tech Stack

- Python
- OpenCV
- YOLOv11
- Ultralytics

## Project Demo

This system analyzes traffic footage and performs intelligent vehicle counting in real time.

## Installation

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/AI-Traffic-Analysis-System.git
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the project:

```bash
python main.py
```
